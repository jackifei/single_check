# oriui 目录说明

本目录用于保存“更贴近当前程序显示效果”的 Qt Designer `.ui` 文件。

这些文件比 `ui/` 目录中的版本更完整，包含：

- 页面顶部检测结果与操作提示栏
- 主要分组、表格、按钮和输入控件
- 流程编辑页的产品模板区
- 硬件配置页的 16 路输入指示灯与 16 路输出按钮
- 运行看板页的统计卡片、相机 ROI 显示和流程步骤状态区
- 暗黑主题 QSS，已预置到各 `.ui` 文件，便于在 Qt Designer 中预览

说明：

1. `.ui` 文件主要供二次布局设计使用，当前 Python 程序仍以 `app/` 中的代码为准。
2. Qt Designer 对某些运行时动态行为（如下拉框单元格、状态切换、实时数据）无法完全展示。
3. 修改 `.ui` 后，可以使用 `pyuic6` 生成 Python UI 代码，再与现有页面逻辑合并。
