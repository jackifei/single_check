# 相机驱动目录

建议每个相机品牌或采集方式一个文件，并实现统一接口。

推荐接口：

```python
class CameraDriver:
    def enumerate_devices(self) -> list[dict]: ...
    def open(self, device_id: str) -> bool: ...
    def close(self) -> None: ...
    def start_preview(self) -> None: ...
    def stop_preview(self) -> None: ...
    def capture(self) -> object: ...
    def get_frame(self) -> object: ...
    def set_exposure(self, value_us: float) -> None: ...
    def set_gain(self, value: float) -> None: ...
    def set_frame_rate(self, value: float) -> None: ...
```

与页面集成时，在 `app/pages/camera_page.py` 中替换“插入点”注释处的 demo 逻辑。
